# 🛡️ คู่มือการใช้งานสำหรับผู้ดูแลระบบ (Admin Guide)
**ระบบสารสนเทศโรงเรียน HONGSON Information Hub**

---

## 📌 บทนำ
คู่มือนี้สำหรับผู้ดูแลระบบสารสนเทศโรงเรียน (Admin) เพื่อใช้ในการตรวจสอบ คัดเลือก แก้ไขข้อมูล และสร้างเล่มรายงานสารสนเทศฉบับสมบูรณ์ (Google Docs & PDF Export)

---

## 🔑 1. การเข้าสู่ระบบ Admin Dashboard
1. คลิกปุ่ม **"เข้าสู่ระบบผู้ดูแลระบบ"** บนหน้าหลัก
2. กรอก **รหัสลับผู้ดูแลระบบ (Admin Code)** (เช่น `HG-ADMIN-2026`)
3. คลิก **"ยืนยันรหัสผ่าน"** เพื่อเข้าสู่ Admin Dashboard

---

## 📊 2. ภาพรวม Dashboard และการกรองข้อมูล
- **Stats Overview Grid:** แสดงสถิติความครอบคลุม (Completeness Rate), จำนวน Submission ทั้งหมด, รายการที่รอตรวจ (`submitted`), รายการที่ตรวจแล้ว (`reviewed`) และรายการที่ถูกคัดออก (`excluded`)
- **11 Categories Grid:** การ์ดสรุปสถานะรายหมวด แสดงจำนวนรายการและไฟสถานะความครบถ้วน
- **Search & Multi-Filter Bar:**
  - ค้นหาด้วยคำค้น (Submission ID, ชื่อผู้ส่ง, หน่วยงาน)
  - กรองตามหมวดสารสนเทศ (หมวด 1 - 11)
  - กรองตามสถานะรายการ (`submitted`, `needs_review`, `reviewed`, `excluded`)

---

## ✏️ 3. การตรวจสอบ แก้ไข และจัดวางเล่ม (Submission Review & Edit Modal)
เมื่อคลิกปุ่ม **"ตรวจ / แก้ไข"** ในตารางรายการ Admin สามารถจัดการสิ่งต่อไปนี้ได้:

1. **ปรับเปลี่ยนสถานะรายการ (Status):**
   - `submitted`: รายการส่งใหม่ รอตรวจ
   - `needs_review`: ต้องการให้ผู้ส่งตรวจสอบเพิ่มเติม
   - `reviewed`: ตรวจสอบความถูกต้องแล้ว
   - `excluded`: คัดออกจากรายงาน (ไม่นำไปรวมในเล่ม PDF)
2. **สวิตช์ Include/Exclude รายการ (`selected_for_report`):**
   - เปิดสวิตช์เพื่อนำ Submission นี้ไปใส่ในรายงาน PDF
3. **แก้ไขข้อมูลฟิลด์และตาราง Dynamic Table:**
   - Admin สามารถปรับแก้ตัวเลข ข้อความ หรือตารางข้อมูลได้โดยตรง
4. **จัดการรูปภาพและจัด Photo Layout:**
   - **สลับเปิด/ปิดการใช้รูป:** คัดเลือกเฉพาะรูปภาพกิจกรรมที่ต้องการแสดงในเล่ม
   - **ปรับเปลี่ยน Caption:** แก้ไขคำบรรยายภาพภาษาไทย
   - **จัดรูปแบบการวางภาพ (Photo Layout):**
     - 🖼️ `Single` (ภาพเดี่ยว): แสดงรูปขนาดใหญ่ 1 ภาพต่อแถว
     - 🖼️🖼️ `Pair` (ภาพคู่ 2x1): จัดรูปเป็นคู่ 2 ภาพเคียงกัน
     - 🧩 `Grid` (ภาพชุด 2x2): จัดรูปเป็นตาราง 4 ภาพ
     - 📑 `Full Page` (เต็มหน้า): จัดรูปแสดงขนาดเต็มความกว้างหน้ากระดาษ

---

## 📄 4. การใช้ Report Builder และสร้างรายงาน PDF (Export Engine)

### ขั้นตอนการสร้างเล่มรายงาน:
1. คลิกปุ่ม **"📄 สร้างรายงาน & Export PDF"** บนมุมขวาบนของ Admin Dashboard
2. หน้าต่าง **Report Builder Modal** จะเปิดขึ้น พร้อมแสดง **Checklist ความพร้อม 11 หมวด**
3. **กำหนดการตั้งค่าเอกสาร:**
   - ระบุ **ชื่อหัวข้อรายงาน** (เช่น *รายงานสารสนเทศประจำปีการศึกษา 2568*)
   - เลือก **ปีการศึกษา**
   - ติ๊กเลือกออปชัน: 📘 หน้าปก (Cover Page), 📑 คำนำและสารบัญ (Preface & TOC), 🖼️ แทรกรูปภาพกิจกรรม
4. คลิกปุ่ม **"🚀 เริ่มสร้าง Google Docs & Export PDF"**
5. **การทำงานของระบบ (Real-time Progress Bar):**
   - ระบบจะสร้าง Google Docs ตาม Schema ทั้ง 11 หมวดอัตโนมัติ
   - ดึงรูปภาพกิจกรรมจาก Google Drive มาวางตาม Photo Layout ที่ Admin เลือกไว้
   - แปลงเอกสารเป็นไฟล์ **PDF** และจัดเก็บบน Google Drive Reports Folder
   - ลงบันทึกประวัติการ Export ในแท็บ `EXPORTS` ของ Google Sheets
6. **เปิดดูและดาวน์โหลด:**
   - เมื่อสร้างเสร็จ ระบบจะแสดงปุ่มเปิด **Google Docs** และ **PDF** โดยตรง
   - สามารถเรียกดูประวัติย้อนหลังและดาวน์โหลดเล่มรายงานย้อนหลังได้ในตาราง **EXPORTS Log**

---

## 🔒 5. ข้อควรระวังความปลอดภัยและการดูแลระบบ
- รหัสลับ Admin ควรถูกจัดเก็บอย่างปลอดภัยและเปลี่ยนเป็นระยะผ่าน **Script Properties**
- ไม่แชร์ Web App URL ที่สิทธิเป็น Admin ให้บุคคลภายนอกที่ไม่เกี่ยวข้อง
